Petly - Tienda La Yunta

Proyecto de Ingeniería de Software para la gestión de productos y control de stock del negocio local Tienda de Mascotas "La Yunta".

 Contenido del repositorio
- wireframe.html: Boceto interactivo con las vistas móvil (cliente) y mostrador (caja rápida).
- index.html: Interfaz básica de prueba conectada al servidor.
- server.js: Servidor en Node.js y Express con las rutas para consultar catálogo y descontar existencias.
- package.json: Dependencias del proyecto.
